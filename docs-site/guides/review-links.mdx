title: "Review links"
description: "Show Dogear only to reviewers who open a link with ?review, and keep the page clean for everyone else."

---

To review a page without everyone else seeing the layer, set `activation="param"` and send reviewers a link with `?review`.

<CodeGroup>

```tsx React
<Comments activation="param" shortcut="c" />
```

```html HTML
<dogear-comments activation="param" shortcut="c"></dogear-comments>
```

</CodeGroup>

- **`?review`** shows the layer, then keeps it for the rest of the tab.
- **`?review=off`** ends it.
- **Plain visitors** see a clean page.

The parameter isn't part of where comments live, so `/pricing?review` and `/pricing` share threads.

## A different parameter

`reviewParam` (`review-param` on the element) changes the query parameter it listens for.

```tsx
<Comments activation="param" reviewParam="feedback" />
```

## Only on preview deploys

In React, `enabled={false}` renders nothing, so you can turn Dogear on per environment.

```tsx
<Comments enabled={process.env.NEXT_PUBLIC_VERCEL_ENV !== "production"} />
```

## Keep comments off parts of the page

`ignore` takes a CSS selector. Pressing on a match does nothing.

```tsx
<Comments ignore="nav, .chat-widget" />
```

## Knowing when comments open

`onActiveChange` is called with `true` or `false` when someone opens or closes comments, or a thread link opens them, such as for analytics. It isn't called on a reload.
