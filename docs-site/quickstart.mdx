<Steps>
  <Step title="Install the package">
    ```bash
    npm install @harshi04/dogear
    ```

    pnpm, yarn and bun work the same way.
  </Step>
  <Step title="Render the comments once">
    Mount Dogear once, near the root of your app.

    <Tabs>
      <Tab title="React">
        ```tsx App.tsx
        import { Comments } from "@harshi04/dogear/react";

        export function App() {
          return (
            <>
              {/* …your app */}
              <Comments shortcut="c" />
            </>
          );
        }
        ```
      </Tab>
      <Tab title="Next.js (App Router)">
        Dogear runs in the browser, so wrap it in a client component.

        ```tsx app/dogear-comments.tsx
        "use client";
        import { Comments } from "@harshi04/dogear/react";

        export const DogearComments = () => <Comments shortcut="c" />;
        ```

        Then render `<DogearComments />` once in `app/layout.tsx`.

        ```tsx app/layout.tsx
        import { DogearComments } from "./dogear-comments";

        export default function RootLayout({ children }: { children: React.ReactNode }) {
          return (
            <html lang="en">
              <body>
                {children}
                <DogearComments />
              </body>
            </html>
          );
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Leave your first comment">
    Open your app and press **C**. Click the button, heading or image you mean, write, and press Enter. Drag instead of clicking to mark an area.
  </Step>
</Steps>

<Note>
  With no adapter, comments are stored in this browser's localStorage. That's enough to try Dogear out, but nobody else sees your comments yet.
</Note>

## Rules that always hold

- Mount the comments once, near the root of the app. The adapter is read once, on mount.
- The author of a comment comes from the server, never from the browser.
- Threads are keyed by path without the query, so `/pricing?review` and `/pricing` share them.
